# MinimalLauncher

Androidホームランチャーです。大きな時計、選んだアプリ、お気に入りのドック、再生中の音楽を1画面にまとめます。対応OSはAndroid 8以降です。

現在はベータ版です。このリポジトリは配布用で、ソースコードは含みません。動作は保証しません。重要な端末では、元のホームへ戻す手順を確認してからお試しください。

## ダウンロード

[Releases](https://github.com/hi7-jp/MinimalLauncher-releases/releases) から最新版の `MinimalLauncher-<版>.apk` を取得します。辞書JAR（`kuromoji-ipadic-0.9.0.jar`）は任意です（[アプリ検索の読みと辞書](#アプリ検索の読みと辞書)）。

### 配布物の確認（任意）

- 各ファイルのSHA-256はReleaseページの各ファイルの横に表示されます。
- APKの署名証明書のSHA-256は次のとおりです。`apksigner verify --print-certs` などで一致を確認できます。

```text
0600c2d6acebdfb579ef39921c78b4c30bd1f10612d905cdbced86307f9d4d4f
```

## 導入

1. APKを端末に保存して開きます。
2. Androidに求められた場合は、APKを開くアプリに「不明なアプリのインストール」を許可し、インストール後に許可を元に戻します。
3. MinimalLauncherを起動し、右上の設定から「既定のホーム」を選びます。Androidのホームアプリ選択画面でMinimalLauncherを選択してください。
4. ホームの＋からアプリを追加し、ドックの空き枠からお気に入りを登録します。

ホームのApplications／Dockではアプリ同士のドラッグ、全アプリ欄では「フォルダ＋」からフォルダを作れます。フォルダを押すと中のアプリを起動でき、編集から名前・中身を変更できます。フォルダを削除してもアプリ自体は削除されません。

アプリの長押しメニューからショートカットの起動や表示の変更ができます。設定の「アプリのアイコン」では、アプリごとに元のアイコン・線画を選べ、ADW・Nova互換のアイコンパックも読み込めます。設定の「全アプリ一覧」では表示状態の切り替えや表示名の変更ができます。

音楽機能を使う場合は設定の「音楽」から通知アクセスを許可します。許可しなくてもホーム機能を使えます。曲が表示されない場合は音楽アプリで再生を開始してください。

## アプリ検索の読みと辞書

設定の「検索」で読み・別名を追加できます。自動読みは初期OFFです。使う場合は同じReleaseの辞書JARをダウンロードし、設定の「検索」→「辞書ファイルを取り込む」で選んでから「自動読みを使う」をONにします。辞書は設定JSONに含まれず、機種変更後は再取得します。

## 更新

新しいAPKを開いて上書きインストールします。設定は保持されるため、アンインストールは不要です。

## 元のホームへ戻す

MinimalLauncherの右上の設定から「既定のホーム」を選び、Androidのホームアプリ選択画面で以前のホームを選択します。MinimalLauncherを開けない場合は、Androidの設定から「アプリ」→「既定のアプリ」→「ホームアプリ」を変更します。項目名は端末により異なります。

## データと権限

- 通知アクセスは再生中のMediaSessionを参照するために使います。通知本文の読み取り・保存、録音、音声キャプチャは行いません。
- インストール済みアプリの一覧は、ホームへの表示のためだけに端末内で参照します。
- アプリの選択、配色、表示、動きなどの設定は端末内に保存します。曲情報・通知本文・アルバム画像は永続保存しません。
- ネットワーク通信権限・解析SDK・広告SDKは含みません。

通知アクセスを許可できない場合は、設定の音楽ページの「許可できない場合」を参照してください。Android 13以降では、信頼できる配布元か確認してから、アプリ情報のメニューで「制限付き設定を許可」を選び、音楽ページへ戻って通知アクセスを許可します。項目がない場合は端末の案内に従ってください。

## 不具合の報告

[Issues](https://github.com/hi7-jp/MinimalLauncher-releases/issues/new/choose) のテンプレートから報告してください。Issueは誰でも閲覧できます。

- インストールしているアプリの名前・アイコン、再生中の曲、通知の内容が写った画像は、隠してから添付してください。
- 設定のバックアップJSONにはアプリの一覧が含まれるため、添付しないでください。
